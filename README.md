# My Agent Demo

## Project Overview

`my-agent-demo` is a sample project showcasing how to build an intelligent agent using OpenAI's GPT models. It includes examples of prompt engineering, tool usage, and response handling.

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/my-agent-demo.git
cd my-agent-demo

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`

# Install dependencies
pip install -r requirements.txt
```

## Usage Examples

### Running the Agent

```bash
python run_agent.py
```

The script will start an interactive session where you can type queries and see the agent's responses.

### Importing as a Library

```python
from agent import Agent

agent = Agent()
response = agent.ask("What's the weather today?")
print(response)
```
